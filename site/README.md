# Website

The source of <https://dylanckoldan-boop.github.io/sentinel-vision/>: plain HTML and CSS generated by `build.py`, with
no JavaScript, cookies or third-party requests.

```bash
pip install --require-hashes -r requirements/site.lock -r requirements/sign.lock
python site/build.py --check            # build into site/public and check links, images, alt text and contrast
python site/build.py --offline --check  # local preview without network access (no release fingerprint shown)
npm ci --prefix site/a11y && python site/check_a11y.py site/a11y/node_modules/axe-core/axe.min.js
```

Without `--offline`, the version, installer fingerprint and signing key shown in *Download and install* come from the
latest GitHub release, and only after its `SHA256SUMS.txt` signature verifies against the keys pinned in
`src/sentinel_vision/trust.py` (`release_check.py`). If it doesn't verify, the build fails and nothing is published.

`.github/workflows/pages.yml` builds and checks the site on every change, publishes it from `main`, rebuilds it after
each release, and then checks that every live page matches what was built.

**Hosting.** GitHub Pages, as an accepted risk: see [SECURITY.md](../SECURITY.md#the-website-is-hosted-on-github-pages-audit-finding-sv-b01)
for the reasoning, what limits the risk, and the review date.
