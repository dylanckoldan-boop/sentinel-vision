# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussions focused on making Sentinel Vision
better. Harassment, personal attacks and discriminatory language are not tolerated.

Report unacceptable behavior privately to the maintainer through GitHub (open a private security advisory if you need a
confidential channel). Reports are handled confidentially.
